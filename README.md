# EcoQuest – Învață să reciclezi!

EcoQuest este o aplicație educațională despre reciclare și protejarea mediului înconjurător.

## Pentru cine este?
Aplicația este destinată elevilor de clasa a XI-a și tuturor celor care vor să învețe mai multe despre reciclare.

## Cum se joacă?
Utilizatorul apasă butonul „Începe aventura!”, răspunde la întrebările despre reciclare și primește puncte pentru răspunsurile corecte.
